# ANTE meeting notes

The team keeps meeting notes here in the existing GitHub repository so decisions, actions and contributions can link directly to the [Kanban board](https://github.com/orgs/ante-rg/projects/1/views/1), code and pull requests. Use one file per actual meeting, named `YYYY-MM-DD-topic.md`, copied from [the template](TEMPLATE.md). Do not create a dated note before the meeting occurs.

Record attendance only after it is verified. Keep private player data, credentials, individual scores, confidential operator details and personal contact information out of public notes. Link to a safe summary or restricted evidence pointer when needed. A meeting note is evidence of what was discussed and decided; it is not evidence that an action was completed.
